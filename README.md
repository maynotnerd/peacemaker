# Выбор порядка трудоустройства

Учебный сервис по проектированию информационных систем. Задание 4, пункты 4.1–4.2 дорожной карты.

Заявитель подаёт анкету и прикладывает подтверждающие документы. Специалист рассматривает заявку, запрашивает недостающие сведения и выдаёт результат. Сервис определяет порядок трудоустройства, следующее действие и срок. В кабинете заявителя доступны результат, история статусов и ранее оказанные услуги.

## Запуск

Нужен Node.js 24 LTS с npm. Выполните из папки solution:

```sh
npm install
npm run build
npm start
```

Откройте http://127.0.0.1:3000. Для работы над исходниками можно запустить npm run dev и открыть адрес из терминала.

SQLite создаётся автоматически в solution/data/applications.sqlite. Каталог можно изменить переменной DATA_DIR. База хранит учётные записи, сеансы, анкеты, файлы, запросы дополнений, историю и результаты.

## Учебные учётные записи

- Специалист уже создан. Телефон +7 999 000-00-01.
- Заявитель регистрируется по другому номеру, например +7 999 000-00-02.
- Код регистрации и входа по умолчанию 123456. Для учебной демонстрации используйте вымышленные данные.

При необходимости настройте SPECIALIST_PHONE и SMS_CODE перед запуском. Код общий для учебного режима. Приложение по умолчанию слушает только локальный адрес.

## Демонстрация

1. Зарегистрируйте заявителя. Подайте анкету с гражданством Таджикистана и отрицательными ответами на три вопроса о статусах.
2. Войдите как специалист, откройте заявку и начните рассмотрение. Запросите подтверждение даты въезда.
3. Войдите как заявитель, откройте запрос, приложите учебный файл и отправьте дополнения.
4. Войдите как специалист, проверьте дополнения и выдайте результат. Для этой анкеты применяется пункт 4.1.
5. В кабинете заявителя откройте «Оказанные услуги», затем завершённую заявку. Покажите результат и историю статусов.

## Структура

- use_case.md, er.md, system_sequence.md, class_sequence.md и classes.md содержат диаграммы.
- solution/ содержит исходники SvelteKit и код работы с SQLite.
- report/video-report.mp4 показывает полный сценарий обеих ролей с текстовыми пояснениями.

Для пункта 4.2 укажите статус высококвалифицированного специалиста или членство в его семье. При пересечении условий 4.2 применяется первым. В остальных случаях, если ни один маршрут не подходит, выдаётся объяснение. Сроки и правила воспроизводят учебную дорожную карту.
